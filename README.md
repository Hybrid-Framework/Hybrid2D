# 🎮 Hybrid - 2D Game Framework

* #### 🔍 Description
  * A lightweight cross-platform game framework written in C#

* #### 🚧 Development
  * Frequent breaking changes
  * Early development

* #### 🖥️ Platforms
  * **Desktop:** Windows, Mac, Linux
  * **Mobile:** Android, iOS
  * **Web:** Browser

* #### 📦 Dependencies
  * [Emscripten](https://github.com/emscripten-core/emscripten) is a complete compiler toolchain to WebAssembly for web support.
  * [Net 8.0](https://github.com/dotnet/runtime) is a cross-platform runtime for mobile, desktop, web applications.
  * [SDL](https://github.com/libsdl-org/SDL) is a simple direct media abstraction layer.
