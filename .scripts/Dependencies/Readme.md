# Build Scripts
These bash scripts are designed for complete automation. They work cross-platform on Windows, Linux, Mac. Using the script is a simple as running the .sh bash script for your specific platform for example "Windows.sh" to build and update the native libs for Windows (requires being on a windows machine). Each bash script has its own dependencies so please check you have them installed and they can be found in the system PATH.

# Complete Features
* Downloads SDL, Image, Mixer, TTF from GitHub source
* Builds SDL, Image, Mixer, TTF for all platform architectures
* Native lib updates
* Clean up all files
* Fully automated

# Required Platforms
* Windows (Windows, Android, Web)
* MacOS (MacOS, IOS)
* Linux (Linux)

# How to use
* Run platform "Windows.sh"
