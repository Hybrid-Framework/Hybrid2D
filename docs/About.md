
Hybrid began as a personal, fully-featured game framework. As development progressed, it became clear that others might benefit from it as well. However, the original version quickly grew complex, with a steep learning curve that made creating and experimenting feel restrictive and time-consuming.

To address this, the project has taken a new direction: simplicity. Hybrid is now designed to be minimal and flexible, allowing you to use it as-is or integrate your own tools. This approach empowers both beginners and advanced users to create anything from simple games to more complex projects — even small game engines — without unnecessary restrictions.

This project was created by Lloyd J Howarth on 29th September 2025. If it wasn't for SDL, Emscripten and Dotnet this project wouldn't be possible.
